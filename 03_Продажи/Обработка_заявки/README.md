# Обработка заявки

Скиллы для анализа обращений пациентов и улучшения обработки заявок.

## Реестр Скиллов

| Название скилла | Тип запуска: Вручную / По расписанию | Какую задачу выполняет |
|---|---|---|
| administrator-call-auditor | Вручную / По расписанию | Аудитирует звонки администраторов и выявляет точки улучшения конверсии и клиентского опыта |

При добавлении нового скилла-автоматизации в эту папку, обязательно обновляй данную таблицу.

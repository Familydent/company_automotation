# Паспорт скрипта

## Название

`Обновить-Дашборд.py` и файл запуска `Запустить-Дашборд.ps1`.

## Для какой системы

Windows 10 или Windows 11.

## Что необходимо

- установленное приложение Codex (оно предоставляет локальный Python);
- PowerShell, который уже установлен в Windows;
- папка со скриптом, Главным Дашбордом и выгрузками.

Дополнительные программы, библиотеки, пароли и интернет не нужны.

## Что делает скрипт

1. Ищет в своей папке Excel-файлы выгрузок, кроме `Главный Дашборд.xlsx`.
2. В каждой выгрузке читает лист `Встречи`.
3. Считает строки заявок по непустой колонке `ID`.
4. Отдельно считает статусы `Ожидает ответ`, `Подтверждено`, `Нужен email` и остальные.
5. Добавляет одну строку с итогами в `Главный Дашборд.xlsx`.
6. После успешной записи переносит исходную выгрузку в подпапку `Архив`.
7. Записывает результат и ошибки в `log.txt` рядом со скриптом.

Если лист или нужные колонки отсутствуют, скрипт не переносит такой файл в
Архив и описывает проблему в `log.txt`.

## Как запускать вручную

1. Закройте Excel-файлы, которые скрипт будет обрабатывать.
2. Скопируйте новую выгрузку в эту папку рядом со скриптом.
3. Нажмите правой кнопкой на `Запустить-Дашборд.ps1`.
4. Выберите «Запуск с PowerShell».
5. Откройте `Главный Дашборд.xlsx` и убедитесь, что внизу добавилась строка.

## Как понять, что всё успешно

- рядом со скриптом создан или обновлён `log.txt`;
- в журнале есть строки `Обработан файл ...` и `Работа завершена успешно.`;
- в `Главный Дашборд.xlsx` появилась новая строка с количеством заявок;
- исходная выгрузка находится в папке `Архив`.

## Ограничения

Скрипт считает все заявки, которые есть в каждом файле выгрузки. В текущем
формате выгрузки нет даты создания заявки, поэтому в Дашборд добавляется дата
и время обработки файла, а не календарный период заявок.
